# Uyên Linh Model

SKILL xây dựng hệ hình ảnh thương hiệu nhất quán từ ảnh tham chiếu.

## Quy tắc chính
- Khóa gương mặt và trang phục theo ảnh tham chiếu người dùng cung cấp.
- Nhân vật tương tác với đạo cụ minh họa nội dung.
- Headline ngắn, rõ, ưu tiên 3–7 từ.
- Bố cục thương mại sạch: text trái, nhân vật phải, đạo cụ trung tâm/dưới trái.
- Ánh sáng cinematic ấm, soft key light, orange-red rim light.
- Màu: cream, yellow, beige, orange-red, charcoal.
- Tỷ lệ: 4:5 post; 9:16 story/reels; 1:1 avatar; 16:9 hero/banner.
- Không tự tạo giá, số liệu, testimonial, thu nhập hoặc logo đối tác.

## Sales page flow
Hero → Problem → Solution → Benefits → How it works → Proof được cung cấp → Offer → FAQ → CTA.
